The baseline LeNet-5 reached 88.54% validation accuracy, while training with RandomAffine reached 89.42%, an improvement of 0.88 percentage points. Data augmentation helped modestly, though with a single run per setting some of this gap could be due to random variation. Augmentation can help CNNs generalize because each epoch shows the model slightly different versions of the same digit, which reduces overfitting to exact pixel positions and encourages features that are robust to small shifts. This fits SVHN well, since house-number digits are often off-center in real photos, so random translations mimic the variation seen at test time. Note that the default pipeline already applies a small random rotation, so the baseline was not completely augmentation-free.
